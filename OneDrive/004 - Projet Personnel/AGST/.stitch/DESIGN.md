## Section 1 — Design Philosophy

**Vibe:** Bold and energetic African sports academy. Mobile-first, warm and high-contrast, rooted in Malian identity. Every element communicates trust, energy, and accessibility. Parents in Bamako must understand the offer in under 10 seconds.

**Principles:**
1. **Mobile-first always** — Design at 375px, enhance upward
2. **Contrast for trust** — Navy + gold reads instantly as credible
3. **Real photos only** — No stock imagery; real children, real stadium
4. **CTA hierarchy** — Gold (primary inscription) > WhatsApp green (contact) > outlined (secondary)
5. **Anti-scam by design** — Warning elements are visually distinct and always present

## Section 7 — Component Patterns

### Page Structure (every page)
```
1. Sticky Navbar (navy, 56px)
2. Page Hero (photo bg + gradient overlay, headline, optional CTA)
3. [Page-specific sections]
4. CTA Section (navy→green gradient, registration + WhatsApp buttons)
5. Footer (navy)
6. Floating WhatsApp button (fixed, bottom-right)
```

### Navigation Bar
```
[Logo 38px] [Brand name + subtitle]    [FR|EN|BM toggle] [☰]
Background: #0D1B48
Shadow: 0 4px 20px rgba(0,0,0,0.14)
```

### CTA Button Hierarchy
```
1st: btn--gold    → Inscription (gold bg, navy text, gold glow)
2nd: btn--whatsapp → Contact WhatsApp (green bg, white text, green glow)
3rd: btn--green   → Secondary actions (green bg, white text)
4th: btn--outline  → Tertiary (transparent, bordered)
```

### Anti-Scam Alert
- Always red/dark-red gradient
- Always starts with ⚠️
- Always mentions "JAMAIS d'argent" + "100% GRATUIT"
- Always shows official WhatsApp number
- Present on: Home (banner), Join (large block), Mission (section)

### Language Support
- French labels used throughout HTML
- `lang="fr"` on `<html>`
- Language toggle in navbar (FR active by default)
- Key phrases in Bambara in hero sub-text (italic, gold-muted)

## Section 8 — Animation & Interaction

| Element | Interaction | Effect |
|---------|-------------|--------|
| Buttons | hover | color darkens, shadow intensifies |
| Gallery items | hover | `scale(1.05)` on img |
| WhatsApp float | hover | `scale(1.08)` + stronger glow |
| Navbar menu | click hamburger | full-screen overlay slides in |
| Language toggle | click | active pill highlights in gold |
| Gallery | touch/scroll | horizontal scroll, no scrollbar visible |

**Transition default:** `all 0.2s ease`
**Gallery scroll:** `overflow-x: auto; -webkit-overflow-scrolling: touch; scrollbar-width: none`
